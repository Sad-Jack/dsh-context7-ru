# dsh-context7

Актуальная документация библиотек для DeepSeek Harness через [Context7](https://context7.com).

Плагин работает на стороне хоста DSH и подключается к официальному Context7 Public APIv2. Агент может получать документацию и примеры для нужной версии библиотеки. Зарегистрированы два инструмента модели:

| Инструмент | Назначение |
|---|---|
| `context7_search` | Поиск библиотек по имени; можно передать вопрос на естественном языке для ранжирования. Возвращает совпадения с идентификаторами Context7, например `/vercel/next.js`. |
| `context7_get_docs` | Документация выбранной библиотеки по ID или обычному имени с автоматическим разрешением, с учётом вопроса и ранжирования: фрагменты кода/документации, правила библиотеки, URL источников. Поддерживает закрепление `version`, например `v15.1.8`, и режим `fast` с меньшей задержкой. |

По описанию исходной версии Context7 допускает доступ без ключа с небольшими лимитами. Для более высоких лимитов можно получить ключ с префиксом `ctx7sk` в [панели Context7](https://context7.com/dashboard). Тарифы и доступность зависят от сервиса.

## Установка

Опубликованный пакет npm:

```bash
dsh plugin --profile web add dsh-context7
```

Из GitHub:

```bash
dsh plugin --profile web add github:Nrxous/dsh-context7
```

После установки перезапустить DSH. Модель может вызывать инструменты, когда ей нужна документация библиотек; запрос можно сформулировать и напрямую.

## Ключ API: необязательно

Задать `config.apiKey` в **слое переопределений профиля** `~/.dsh/profiles/<name>/cordis.patch.yml`. Он применяется после слоёв наборов плагинов и сохраняется при их обновлении:

```yaml
- id: dsh-context7
  config:
    apiKey: ctx7sk_your-key-here
```

Сохранить и перезапустить DSH. При наличии ключа запрос содержит `Authorization: Bearer`; без ключа действуют лимиты доступа без авторизации.

## Разработка

Плагин на JavaScript, отдельная сборка не нужна. Точка входа `main: src/index.js`, зависимость времени выполнения `@deepseek-ai/schemastery` предоставляется хостом.

```bash
# Hot-mount into the web profile (no restart)
dev_install_package <this-directory>
# or inside the injector environment
dev_inject_plugin <this-directory>
```
